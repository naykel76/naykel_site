# Website Status (review)

Tracks integration and checks for the features selected in the
[design brief](_design-brief.md). Package reviews remain in their own status files.

## Status Key (review)

| Label  | Meaning                                     |
| ------ | ------------------------------------------- |
| ✅      | Confirmed complete for this column          |
| review | Present or attempted, awaiting confirmation |
| blank  | Not yet recorded as complete                |

**Added to site** means integrated into the application. **Checked on site** means
the agreed behaviour has been verified there. A feature can work on this site
while its broader package review remains outstanding.
