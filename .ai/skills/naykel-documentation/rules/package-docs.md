# Package Docs

## Doc Placement

- Put how-to pages in `guides/`.
- Put technical class, base-class, trait, and API-style docs in `reference/`.
- Do not put technical reference material in `guides/` just because the subject
  happens to be a Livewire component or framework class.

## Top-Level Package Docs

Use for top-level package or framework documentation such as Gotime and Authit.

```markdown
1. ## Installation
2. ## How It Works    ← mental model, keep short
3. ## Basic Usage     ← minimum working example
4. ## Configuration   ← options, config files
5. Additional sections as needed
```

Rules:

- Show a working example as early as possible.
- Link to component docs rather than repeating their content.
